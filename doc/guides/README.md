## 四步流程

1. 配置 DeepSeek 模型服务：到 [DeepSeek API 开放平台](https://platform.deepseek.com/api_keys) 创建 API Key，填入并保存。
2. 用 AI 建方向模板：勾选隐私说明，上传图片简历或粘贴文本，按向导确认。
3. 核对并保存模板配置：上传模板图片简历，保存并激活模板。
4. 今日 → 确认生效模板和 BOSS 登录状态 → 手动开始投递。

> 真实发送不会自动开始；所有发送都要经过身份、文字和图片确认。遇到 UNKNOWN 时到「待办 → 需手动核对」处理。
