# OfferChaser 新手快速上手（简版）

> 第一次使用只要 **7 步，约 10–20 分钟**。
>
> 完整细节在 [11a-beginner-guide-full](11a-beginner-guide-full.md)；先按本页走通第一轮。

---

## 第 1 步：启动

双击桌面快捷方式，或进入 `OfferChaser-2.0.1` 目录双击：

```text
OfferChaser.vbs
```

等约 10–30 秒，直到管理台打开：

```text
http://127.0.0.1:6866
```

如果没自动打开，手动访问上面的地址。

---

## 第 2 步：进入管理台

管理台默认免登录，打开后直接进入。

如果以后在配置里把认证打开了（`offerchaser.security.auth-enabled=true`），才需要用安装目录里的令牌登录：

1. 打开安装目录里的 `data\local-session-token`；
2. 用记事本复制里面的一整行令牌；
3. 粘贴到登录门；
4. 点击 **登录管理台**。

令牌相当于本机钥匙，不要发给别人。

---

## 第 3 步：扫码登录 BOSS

首次启动会打开一个 Chrome 窗口：

1. 用 BOSS App 扫码登录；
2. 登录后保持 Chrome 窗口打开；
3. 回到管理台继续操作。

首次使用时管理台显示“未登录”是正常的，程序不附带任何 BOSS 登录态。

---

## 第 4 步：填模型服务

进入顶部 **配置** 空间：

1. 找到 **模型服务（全局）**；
2. 填：

| 字段 | 内容 |
|---|---|
| API Base URL | 你的 OpenAI 兼容接口地址 |
| 模型名称 | 服务商给的模型 ID |
| API Key | 你的密钥 |

3. 点击 **保存模型配置**。

---

## 第 5 步：建一个最小模板并激活

仍在 **配置** 空间，进入方向模板：

1. 点击 **新建模板**（也可以点 **AI 帮我建模板**：上传/粘贴简历 → 确认画像 → 选方向 → 回答 5 个问题 → 保存未激活草稿）；
2. 名称随便填，例如“第一次试跑”；
3. 打开 **编辑配置**，只改下面几项：

| 项目 | 第一次建议 |
|---|---|
| 关键词 | 只填 **1 个** |
| 城市 | 只选 **1 个** |
| 每关键词候选上限 | **1–2** |
| 单关键词采集时长 | **2–5 分钟** |
| 连续无新增窗口 | 默认即可 |
| 筛选规则 | 默认即可 |
| AI 开关 | 打开 |
| AI 介绍/提示词 | 默认即可 |
| 图片简历 | 有就上传；没有就留空 |

4. 点击底部 **保存配置**；
5. 回到模板列表，点击 **激活**，确认“下一轮生效”。

> 只做这些就够开始。规则、简历、AI 细节可以第一轮之后再慢慢调。

---

## 第 6 步：开始第一轮投递

进入顶部 **今日** 空间：

1. 确认右上角运行胶囊显示空闲；
2. 点击 **开始投递**；
3. 第一次只建议投 **1–2 个岗位**；
4. 观察运行胶囊和事件流，不要长时间离开电脑。

如果出现异常：

- 点击运行胶囊里的 **停止投递**；
- 等状态结束，不要直接杀进程。

---

## 第 7 步：看结果，处理待办

一轮结束后，主要看两个地方：

### 今日
- 运行状态；
- 今日文字确认数；
- 待人工核对数；
- 预算使用情况；
- 状态同步。

### 待办（`/boss/inbox`）

只有需要你判断的事情才会出现在这里：

| 情况 | 你做什么 |
|---|---|
| 投递结果 UNKNOWN | 选裁定结果 + 填原因 → 提交人工核对 |
| 规则/AI REVIEW 需要放行 | 批准入队或拒绝，填原因 |
| 建议跟进 | 批准或拒绝，填原因 |
| 图片补发 | 生成计划，仍需后续批准 |

记住：**批准/放行只进入下一轮队列，不会立即发送。**

---

## 结束后

### 停止

- 只停任务：运行胶囊 → **停止投递**；
- 完全退出：托盘右键退出，或双击 `停止OfferChaser.vbs`。

### 备份

使用后，这些目录包含个人数据，**不要发给别人**：

```text
db\
data\
browser-data\
```

需要手动备份时，退出程序后复制这三个目录。

---

## 第一次只要记住这 5 个默认值

| 项目 | 建议 |
|---|---|
| 关键词 | 1 个 |
| 城市 | 1 个 |
| 每关键词候选上限 | 1–2 |
| 采集时长 | 2–5 分钟 |
| 人工放行/跟进 | 先处理，不急着批量批准 |

---

## 常见问题

| 现象 | 处理 |
|---|---|
| 管理台打不开（白屏 / 一直转圈） | 先等 30 秒；确认托盘在运行；手动访问 <http://127.0.0.1:6866/boss>；重启程序；看 `target\logs\offerchaser.log` |
| 管理台要求登录 | 默认已关闭登录（`offerchaser.security.auth-enabled=false`）。只有自己把认证打开后才需要令牌：复制 `data\local-session-token` 里的一整行粘贴登录 |
| 开始按钮不可用 | 可能运行中/停止中/worker 未退出；先停止或强制复位 |
| 提示 BOSS 未登录 | 回 Chrome 窗口重新扫码 |
| AI 全部报错 | 检查模型服务地址、模型名、API Key 和网络 |
| 409 冲突 | 刷新页面后按最新状态操作 |
| 任务卡住 | 先停止，再强制复位；不要直接杀进程 |
